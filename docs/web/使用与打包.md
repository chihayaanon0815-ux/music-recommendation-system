# 网页运行与打包

从仓库根目录执行 `python -m pip install -r packaging/requirements.txt`，再执行 `python packaging/launcher.py`。启动器仅监听 127.0.0.1，依次尝试 5000–5020 端口，自动打开浏览器；关闭控制台或按 Ctrl+C 退出。浏览器关闭不会停止服务。

数据放在仓库根目录 `data/processed/songs.csv` 和 `data/processed/genre_counts.csv`；前者缺失或损坏时显示虚构演示样例，后者缺失时风格图提示未生成。歌手图按当前歌曲统计。B 的 `recommender.recommend` 可导入时使用真实模块，否则页面标明模拟算法。选择风格和歌手后点击生成，清除选择可恢复默认；可用互不匹配的风格和歌手组合验证无结果。

在 Windows 64 位构建机上运行 `packaging\build.bat`。完成后复制 `dist\MusicRecommendation` 整个目录，将 `data\processed\songs.csv` 和 `genre_counts.csv` 放在 `MusicRecommendation.exe` 同级的 `data\processed` 下，双击 exe。构建前需集成 B 模块；Flask 和 PyInstaller 是构建机依赖，目标机无需单独安装 Python、Java。请确认可分发数据的许可。不要只复制 exe，必须保留整个目录。

测试：`python -m unittest discover -s tests/web -v`。最终包必须在另一台无 Python、Java 和网络的 Windows 机器验收：启动、风格/歌手选择、无匹配、两张图、退出、中文路径、端口占用。此环境尚未完成该验收，真实数据和 B 模块联调也待完成。
