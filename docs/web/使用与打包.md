# 网页运行与打包

在仓库根目录执行 `python -m pip install -r packaging/requirements.txt`，再执行 `python packaging/launcher.py`。启动器仅监听 127.0.0.1，依次尝试 5000–5020 端口并打开浏览器。关闭控制台窗口或按 Ctrl+C 退出；关闭浏览器不会停止服务。

源码从仓库根目录 `data/processed/songs.csv` 和 `data/processed/genre_counts.csv` 读取数据。歌曲文件缺失或损坏时明确标记虚构演示样例；风格统计缺失时提示尚未生成。推荐模块不存在时标记模拟算法，模块内部导入错误不会被静默隐藏。输入不存在的歌手可验证无匹配提示。

## Windows 测试版构建

在 64 位 Windows 构建机上准备 B 的 `recommender/` 模块，并在仓库根目录运行 `packaging\build.bat`。产物是 `dist\MusicRecommendation-TEST\`，可执行文件名为 `MusicRecommendation-TEST.exe`。脚本不会自动复制数据；需要手动将两个 CSV 复制到 EXE 同级目录：

```text
MusicRecommendation-TEST/
  MusicRecommendation-TEST.exe
  _internal/                      （完整保留）
  data/processed/songs.csv
  data/processed/genre_counts.csv
```

复制整个 `MusicRecommendation-TEST` 目录到目标电脑，双击 EXE。构建机需要 Python、Flask 和 PyInstaller；目标电脑无需单独安装 Python 或 Java。数据来源和再分发权限应按 A 的数据文档确认；Spotify 衍生数据目前仅用于组内联调，公开再分发权限尚未确认。
