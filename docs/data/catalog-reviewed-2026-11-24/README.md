# 曲库复核版本

版本为 2026-11-24-reviewed，保留全部 293,864 条记录。歌曲文件继续使用 UTF-8 四列格式，推荐权重建议随交付包提供。

317 首曲风冲突和 4,012 组疑似重复均经过来源记录复核。曲风冲突尚未获得足够证据确定单一风格，因此保留原有标签，明细见交付包的 genre_conflict_review.csv。疑似重复中 1 组共享来源曲目 ID，其余组有来源 ID 但录音关系尚待核实，全部记录依约保留。曲库仍含已有的艺人和模型推断标签，推荐权重尚待联调。

公开仓库分支提供版本清单与校验工具。完整 CSV 和逐曲复核证据从课程工作区的本地交付包获取。混合曲库含来源再分发授权尚未确认的数据。

解压交付包后，用 Python 3.11 或更新版本执行以下命令，将路径指向包含歌曲和统计 CSV 的目录。

```powershell
python verify_catalog_release.py "路径/新版曲库-复核版"
```

校验包括文件 SHA-256、曲目总数、ID 唯一性、字段契约、风格计数与复核表引用。
