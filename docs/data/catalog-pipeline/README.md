# 曲库扩充与复核交接

本轮从 A 组交付曲库的 89,740 行出发，按千名艺人采集，经名称归一、跨来源去重、曲风清洗及复核，生成 293,864 条的 `2026-11-24-reviewed` 曲库。新版保持 UTF-8 四列 `song_id,song_name,artist,genres` 与统一曲风计数接口。

- [交接总结](交接总结.md)记录艺人名单、采集断点、标签证据和复现顺序。
- [采集统计](collection-summary.json)、[合并清洗统计](cleanup-summary.json)、[标签归一统计](taxonomy-summary.json)、[质量验收](quality-summary.json)记录各阶段产量和抽查结果。
- [曲库版本清单](catalog-manifest.json)记录本轮完整曲库文件校验值。逐曲复核中的 317 条标签冲突和 4,012 组疑似重复仍随组内交付保留。
- 仓库的 `tools/catalog_pilot/` 和 `tools/catalog_pipeline/` 保存试采和正式处理脚本。历史脚本相对路径基于组内交接包的原目录结构。复跑历史阶段时在交接包副本中将前者复制到 `work/`、后者复制到 `work/music_collector/`，并使用交接包内对应阶段输入。

完整曲库、原始响应、完整逐曲证据及本机生成的索引归入课程组内交付。这个公开分支提供源码、汇总报告和数据校验清单，供获得组内数据的协作者复现。部分外部来源字段的再分发许可仍待核实。
